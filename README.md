# تمرین‌های جاوااسکریپت — A / B

یک صفحه‌ی ساده برای نمایش تمرین‌های JavaScript دو نفر، به تفکیک شخص و شماره‌ی تمرین.

## ساختار پروژه

```
exercises/
  helia/
    ex-01.js
    ex-02.js
  erfan/
    ex-01.js
manifest.json      ← به صورت خودکار توسط GitHub Action ساخته می‌شود
index.html
style.css
script.js
.github/workflows/build-manifest.yml
```

## نحوه‌ی کار

1. هر شخص تمرین جدیدش را به صورت یک فایل `.js` داخل پوشه‌ی خودش
   (`exercises/helia/` یا `exercises/erfan/`) اضافه می‌کند.
   نام‌گذاری فایل‌ها به صورت `ex-01.js`, `ex-02.js`, ... پیشنهاد می‌شود.
2. تغییرات را کامیت و push می‌کند.
3. یک GitHub Action به صورت خودکار پوشه‌ی `exercises/` را اسکن کرده،
   `manifest.json` را می‌سازد و همان لحظه کامیت می‌کند.
4. Vercel با هر push (چه از خود کاربر، چه از Action) دوباره دیپلوی می‌کند
   و صفحه‌ی آنلاین لیست تمرین‌های جدید را نشان می‌دهد.

## استفاده از صفحه

- بالای صفحه بین تب «هلیا» و «عرفان» جابه‌جا شوید.
- از فهرست سمت راست، شماره‌ی تمرین مورد نظر را انتخاب کنید.
- کد تمرین (فقط نمایش) در پنل بالا دیده می‌شود.
- با دکمه‌ی «اجرا»، کد در یک iframe ایزوله اجرا می‌شود و خروجی
  `console.log` / `console.error` / `console.warn` در پنل «خروجی» نمایش
  داده می‌شود — نیازی به باز کردن DevTools نیست.

## راه‌اندازی روی Vercel

1. این پوشه را در یک ریپوی جدید روی گیت‌هاب push کنید.
2. در Vercel، ریپو را import کنید — چون پروژه استاتیک است (بدون build)،
   Framework Preset را روی **Other** بگذارید و Build Command را خالی
   بگذارید (فقط فایل‌های استاتیک سرو می‌شوند).
3. هر push به شاخه‌ی `main` به‌صورت خودکار دیپلوی می‌شود.

## نکته درباره‌ی Action

فایل `.github/workflows/build-manifest.yml` نیاز به دسترسی نوشتن روی
ریپو دارد (`permissions: contents: write` که از قبل در فایل تنظیم شده).
اگر در تنظیمات ریپو، دسترسی پیش‌فرض Actions روی «Read only» باشد،
باید از مسیر زیر آن را به «Read and write» تغییر دهید:

`Settings → Actions → General → Workflow permissions`
